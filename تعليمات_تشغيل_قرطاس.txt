================================================================
   نظام قِـرْطَاس المدرسي - تعليمات التثبيت والتشغيل
================================================================

للتشغيل على جهاز جديد، اتبع الخطوات التالية بالترتيب:

----------------------------------------------------------------
الخطوة 1 - تثبيت Node.js
----------------------------------------------------------------
قم بتنزيل Node.js من الموقع الرسمي:
https://nodejs.org

اختر النسخة LTS (الموصى بها) وثبّتها بشكل عادي.
(هذه الخطوة مرة واحدة فقط لكل جهاز)

----------------------------------------------------------------
الخطوة 2 - فك ضغط المشروع
----------------------------------------------------------------
انسخ ملف qirtas_source.zip إلى الجهاز الجديد.
ثم فك ضغطه في أي مكان تريده، مثلاً:
C:\qirtas

----------------------------------------------------------------
الخطوة 3 - تثبيت مكتبات المشروع
----------------------------------------------------------------
1. افتح Command Prompt (موجه الأوامر)
2. انتقل إلى مجلد المشروع بكتابة:
   cd C:\qirtas\qirtas
   (أو المسار الذي فككت فيه الضغط)
3. اكتب الأمر التالي واضغط Enter:
   npm install
   (سيقوم بتنزيل المكتبات - يحتاج إنترنت مرة واحدة فقط)

----------------------------------------------------------------
الخطوة 4 - تشغيل النظام
----------------------------------------------------------------
في نفس النافذة اكتب:
   npm start

----------------------------------------------------------------
الخطوة 5 - فتح النظام في المتصفح
----------------------------------------------------------------
افتح أي متصفح (Chrome أو Edge) واكتب:
   http://localhost:3000

================================================================
   بيانات الدخول الافتراضية
================================================================

المدير العام   : اسم المستخدم: admin  | كلمة المرور: 123
المحاسب        : اسم المستخدم: acc    | كلمة المرور: 123
شؤون الطلبة   : اسم المستخدم: std    | كلمة المرور: 123
شؤون الموظفين : اسم المستخدم: hr     | كلمة المرور: 123

================================================================
   ملاحظات مهمة
================================================================

- لا تغلق نافذة Command Prompt أثناء استخدام النظام
- لإيقاف النظام: اضغط Ctrl+C في نافذة Command Prompt
- لإعادة التشغيل في المرات القادمة: نفّذ فقط "npm start"
  (لا حاجة لإعادة npm install)
